# 📈 MokTradeDesk

پلتفرم جامع مدیریت حساب‌های معاملاتی، آنالیز استراتژی، مدیریت حساب‌های پراپ (Prop Desk)، دفتر کل مالی و ژورنال روان‌شناسی معامله‌گری.

---

## 🎨 ویژگی‌های اصلی

- **Strategy Lab:** مقایسه نسخه‌های مختلف استراتژی، شبیه‌سازی مونت‌کارلو (Monte Carlo) برای سنجش احتمال ورشکستگی و آنالیزهای زمانی سودآوری.
- **Prop Desk Management:** مدیریت کامل Stageها، محاسبه خودکار دراودان روزانه و کل، هشدار ریسک و ثبت برداشت‌ها.
- **Personal Ledger & Journal:** دفتر کل دوطرفه برای PnL، هزینه‌ها (VPS و چالش‌ها)، برداشت‌های پراپ و ثبت کیفیت اجرا و حالات روحی معامله‌گر.
- **Universal Data Import:** واردسازی و پارس خودکار گزارش‌های Soft4X، MT4/MT5، cTrader و CSV.
- **Auto-Backup System:** ایجاد نسخه پشتیبان ZIP از اطلاعات دیتابیس و اسکرین‌شات‌های چارت به‌صورت زمان‌دار.
- **Cyber Dark UI:** رابط کاربری مدرن Glassmorphism با TailwindCSS و نمودارهای Recharts.

---

## 🛠 پیش‌نیازها

- **Python 3.9+**
- **Node.js 18+** و **npm**
